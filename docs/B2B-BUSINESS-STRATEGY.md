# Queen's Blend B2B Business Strategy & Website Repositioning

**Document Version:** 1.0
**Date:** August 31, 2026
**Status:** Strategic Planning - Ready for Implementation

---

## Executive Summary

Queen's Blend is transitioning from a B2C retail-focused website to a **B2B bulk tea exporter and wholesaler** focused on supplying businesses with premium tea in multiple formats. This document outlines the required strategic changes to align the website, content, and SEO with this business model.

**Current State:** Website positioned as retail/consumer tea shop
**Target State:** B2B bulk exporter/wholesaler platform
**Timeline:** Immediate implementation required

---

## Part 4: Dual-Intent Implementation (No Breaking Changes)

### Core Principle: Additive, Not Replacive

We are **adding B2B content layers** to existing pages, not replacing B2C functionality. This ensures:

- ✅ Current B2C users see no disruption
- ✅ B2B users find their path naturally
- ✅ One URL serves both audiences
- ✅ Single data source (product catalog)
- ✅ No maintenance overhead from separate systems

### SEO Benefits of Single URL

**Without Dual-Intent (Current Problem):**

```
/products (B2C) vs /business/products (B2B)
→ Authority split between two pages
→ Google doesn't know which to rank
→ Weak rankings for both audiences
```

**With Dual-Intent (Proposed):**

```
/tea/darjeeling-black (both audiences)
→ Single page with consolidated authority
→ Google understands topical relevance (both audiences)
→ Stronger rankings for both consumer + business keywords
→ One page answers both search intents naturally
```

## Part 6: Data Architecture

### Single Product Source (No Duplication)

**File:** `data/product-catalog.json`

```json
{
  "id": "darjeeling-black-001",
  "name": "Darjeeling Black Tea",
  "slug": "darjeeling-black",

  "b2c": {
    "description": "Premium Darjeeling black tea for tea connoisseurs",
    "shortDescription": "Floral, muscatel, bright",
    "heroImage": "/images/darjeeling-hero.jpg",
    "productImage": "/images/darjeeling-product.jpg",
    "keywords": ["darjeeling tea", "buy tea online", "premium black tea"],
    "shopCTA": "Shop Now",
    "retailPrice": 299,
    "minRetailQuantity": 50 // grams
  },

  "b2b": {
    "businessDescription": "Bulk Darjeeling tea for hotels, restaurants, and retail",
    "formats": ["single-chamber-bags", "tea-pods", "loose-leaf-tin", "bulk-box"],
    "minimumOrderQuantity": 5000, // grams (5kg)
    "keywords": ["darjeeling tea supplier", "bulk tea export", "wholesale darjeeling"],
    "businessCTA": "Request Quote",
    "useCases": ["hotels", "restaurants", "retail", "private-label"]
  },

  "shared": {
    "tastingNotes": "Muscatel, floral, bright",
    "origin": "Darjeeling, West Bengal, India",
    "brewTime": "3-4 minutes",
    "brewTemperature": "85-90°C",
    "ingredients": "100% Darjeeling Black Tea"
  }
}
```

**Key Points:**

- Single record per product
- B2C and B2B metadata separated but coexist
- Shared data (taste, origin, brewing) used by both
- No duplication, no conflicts
